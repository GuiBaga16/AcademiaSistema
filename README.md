# Academia-Sistema

Sistema de cadastro de alunos da academia e equipamentos:

## BAGAGYM

Sistema de gerenciamento de academia desenvolvido em Java, com o objetivo de facilitar o cadastro e gerenciamento de alunos e equipamentos.

## Funcionalidades

* Cadastro de alunos
* Cadastro de equipamentos
* Gerenciamento dos registros da academia

## Tecnologias

* Java
* Maven
* PostgreSQL
* JDBC
* Git
